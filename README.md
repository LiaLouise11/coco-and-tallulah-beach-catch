# Coco and Tallulahs beach catch

A colourful 20-second beach fishing game. Choose Coco, Tallulah, Winter or Portia, jump for fish and dodge sharks!

## Play

Once GitHub Pages is enabled: https://lialouise11.github.io/coco-and-tallulah-beach-catch/

- Move: arrow keys or A / D
- Jump: Space or the on-screen Jump button
- Pause: P
- Restart: R

Regular fish earn 1 credit, gold fish 2, the rare purple fish 10, and the silver glitter fish 50. Add up to ten players and take turns. The Top 3 scoreboard updates automatically; scores and nicknames are stored only in each browser.

The browser game is self-contained in `index.html`. No build or dependencies are required.

Inspired by https://github.com/Tingsters/Phippy-Gaming-Workshop. All game artwork is drawn directly in code.
